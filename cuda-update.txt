Updating the CUDA toolkit (Ubuntu 24.04 "noble", x86_64)
=========================================================

Context: nvcc came from Ubuntu's own apt repo (package "nvidia-cuda-toolkit",
version 12.0.140~12.0.1-4build4, from us.archive.ubuntu.com/ubuntu
noble/multiverse). That package is frozen at CUDA 12.0 for the life of the
Ubuntu release and predates Blackwell (RTX 5090 / sm_120) support. The
driver (580.173.02) is already new enough (reports CUDA 13.0 capability) --
only the toolkit/nvcc needs replacing. Do NOT remove the driver package.


1. Remove the old Ubuntu-packaged toolkit
------------------------------------------
sudo apt remove --purge nvidia-cuda-toolkit nvidia-cuda-toolkit-doc nvidia-cuda-dev \
    nvidia-cuda-gdb nvidia-profiler nvidia-visual-profiler libcupti-dev libcupti-doc libcub-dev
sudo apt autoremove


2. Add NVIDIA's own CUDA apt repo
-----------------------------------
wget https://developer.download.nvidia.com/compute/cuda/repos/ubuntu2404/x86_64/cuda-keyring_1.1-1_all.deb
sudo dpkg -i cuda-keyring_1.1-1_all.deb
sudo apt update


3. Install a current toolkit
------------------------------
# latest available (currently CUDA 13.x) -- matches the driver's reported capability
sudo apt install cuda-toolkit-13-0

# or pin a specific version if jax/jaxlib/jax-finufft need an exact match, e.g.:
sudo apt install cuda-toolkit-12-8

(Optional: run `apt list -a cuda-toolkit-13-0` first to see exactly what
versions are on offer before picking one.)


4. Point your shell at the new nvcc
--------------------------------------
apt installs it under /usr/local/cuda-X.Y/bin, not /usr/bin, so it will not
silently replace the old one on PATH until you say so:

export PATH=/usr/local/cuda-13.0/bin${PATH:+:${PATH}}
export LD_LIBRARY_PATH=/usr/local/cuda-13.0/lib64${LD_LIBRARY_PATH:+:${LD_LIBRARY_PATH}}

Add those two lines to ~/.bashrc (or ~/.zshrc) to make them persistent.
NVIDIA also drops a symlink /usr/local/cuda -> /usr/local/cuda-X.Y, so
/usr/local/cuda/bin works too and survives future version bumps if you
re-point the symlink instead of hardcoding the version number.


5. Verify
-----------
hash -r   # clear the shell's cached path to the old /usr/bin/nvcc
which nvcc
nvcc --version

You should see the new version, not 12.0.140.


6. Next step (once this is done)
------------------------------------
Building jax-finufft from source against cuFINUFFT should then be able to
target sm_120 for the RTX 5090, which the PyPI wheel does not support (it
ships CPU-only kernels). That's a separate follow-up once nvcc is current.
